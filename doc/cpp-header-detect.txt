*cpp-header-detect.txt*  Detect whether a .h file is C or C++

Author:  Jan Claussen
License: MIT

==============================================================================
INTRODUCTION                                       *cpp-header-detect*

Vim treats every .h file as either C or C++, depending on |c_syntax_for_h|.
This plugin decides per file instead:

1. If a source file with the same name exists next to the header, its
   language wins. foo.cpp, foo.cc, foo.cxx and foo.c++ make foo.h C++,
   foo.c makes it C.
2. Otherwise the first lines of the header are searched for C++ keywords
   such as `class`, `namespace` or `template` and for constructs like
   `std::` or `<vector>`.
3. If nothing is found, the header is C.

The filetype is only changed when it differs, so the |FileType| autocommands
do not run twice.

==============================================================================
COMMANDS                                           *cpp-header-detect-commands*

                                                   *:CppHeaderDetect*
:CppHeaderDetect        Detect the filetype of the current buffer again, e.g.
                        after adding the first C++ code to a new header.

==============================================================================
OPTIONS                                            *cpp-header-detect-options*

                                                   *g:cpp_header_detect_lines*
g:cpp_header_detect_lines
                        Number of lines to search. Default: 100

                                                   *g:cpp_header_detect_default*
g:cpp_header_detect_default
                        Filetype when no C++ is found. Default: 'c'

                                          *g:cpp_header_detect_cpp_extensions*
g:cpp_header_detect_cpp_extensions
                        Extensions of C++ source files that are looked for
                        next to the header.
                        Default: ['cpp', 'cc', 'cxx', 'c++']

                                                *g:cpp_header_detect_keywords*
g:cpp_header_detect_keywords
                        Additional words that mark a header as C++. They are
                        matched as whole words. Default: []

                                                *g:cpp_header_detect_patterns*
g:cpp_header_detect_patterns
                        Additional regular patterns that mark a header as
                        C++. Default: []

==============================================================================
FUNCTIONS                                        *cpp-header-detect-functions*

cpp_header_detect#Guess({bufnr})                 *cpp_header_detect#Guess()*
                        Returns 'c' or 'cpp' for buffer {bufnr} without
                        changing anything.
